# Rain Check – landing page

Landing page for **Rain Check**, a generic version of the Atlantic Edge
rebooking alpha, aimed at owner-run surf, SUP and kayak schools on the Wild
Atlantic Way. Plus `notes.html` (Behind the build, placeholder for now).

**Live page:** https://kellyjason82.github.io/atlantic-edge-landing-page/

## How to open

Open `index.html` in any web browser. One file, no install or build step.

## Notes

- The waiting-list form does **not** send or store anything; it only shows a
  thank-you message on the page.
- Price is early-access pricing and an assumption.
- Features not in the alpha are listed under "Planned".
